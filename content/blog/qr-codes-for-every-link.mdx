A short link is already easier to type or read out loud than a long one. But plenty of places a link ends up aren't typed at all — a poster, a flyer, a menu, a business card, the side of a box. For those, what you actually want isn't something to read, it's something to scan.

So every link you create on squish.to now comes with a QR code automatically.

## What changed

Create a link the same way you always have — paste a URL, pick a slug if you want one, hit squish — and right next to "Copy link" you'll now see a QR code, ready to download as a PNG. No separate QR generator, no extra step, no account required.

Scan it with any phone camera and it goes exactly where the link goes. Print it, stick it on something, put it in a slide deck — it's just an image once it's downloaded.

## File uploads get it too

If you're using squish.to to [upload a file](/upload) and share a link to it, the same QR code shows up there as well. One scan, straight to the file — handy for anything you'd rather hand someone physically than text them a link for.

## Nothing else changes

Still free, still no account, still the same link you'd have gotten before — the QR code is just sitting there next to it now, in case the person on the other end would rather point a camera than type.

Go [squish a link](https://www.squish.to) and see it for yourself.
