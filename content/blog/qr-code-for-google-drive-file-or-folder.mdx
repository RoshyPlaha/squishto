# QR Code for a Google Drive File or Folder: Make It Scannable and Safe to Print

![Coral QR-style tile with rings, dots and a squiggle, illustrating a QR code for a Google Drive file](/blog/qr-code-for-google-drive-file-or-folder.svg)

To make a QR code for a Google Drive file or folder, set its sharing to "Anyone with the link" as Viewer, copy the share link, and paste it into [squish.to](https://squish.to). You get a short link and a downloadable QR code right beside it. Scan it with a phone before you print. A short link makes a simpler, easier-to-scan code than a long Drive URL.

This works for a file, a folder, or a Doc, Sheet or Slides deck. The steps below cover the one setting that trips people up, why the short link helps, and a quick test to run before the flyer goes to the printer.

## Step 1: Set sharing in Drive first

The QR code only opens what Drive lets the scanner open, so do this before anything else.

1. In Google Drive, right-click the file or folder and choose **Share**.
2. Under **General access**, choose **Anyone with the link**.
3. Set the role to **Viewer**. For handouts, menus, schedules and photo albums, that is what you want.
4. Click **Copy link**.

If you leave it on Restricted, people who scan will hit a request-access screen. That is the most common reason a printed Drive QR code "doesn't work". Restricted is still the right choice for private files, but then a printed code is the wrong tool, because strangers can scan it too.

One thing to know for folders: anyone with the link can see everything inside the folder, including files you add later. If the folder is a mix, make a fresh folder for the QR code and put only the public files in it.

## Step 2: Shorten the link, get the QR code

1. Paste the Drive link into the box at [squish.to](https://squish.to).
2. Optionally pick your own ending, such as `squish.to/club-schedule`. Custom endings are 3 to 30 characters: letters, numbers and hyphens.
3. Click squish. Your short link appears, with a QR code next to it.
4. Click **Download QR** to save it as a PNG.

No account is needed. If you also want to read the link out loud or print it under the code, a name like `club-schedule` works well for that. There is more on the Drive side in [how to shorten a Google Drive link](/blog/how-to-shorten-a-google-drive-link).

## Why a short link makes a better QR code

A QR code stores the text of the link. The longer the link, the more squares the code needs, and the smaller each square becomes at a given print size. A full Drive URL is long, with an ID of around 33 characters. A short link is far shorter, so the code has fewer, bigger squares. That generally scans faster, from further away, and survives a slightly blurry print better.

## Step 3: Test before you print

- Scan the downloaded code with your own phone, ideally on mobile data rather than your Wi-Fi.
- Scan it from a second phone that is not signed in to your Google account. If it asks for access, go back to Step 1.
- Print one copy at the real size and scan that, not just the screen.
- Leave a blank border around the code and keep strong contrast, dark squares on a light background.

## What you can and cannot see afterwards

Every scan is a click on the short link, so the stats page (add your code at `squish.to/stats`) shows total opens, the last 7 days, your busiest day, a 14-day chart, and recent opens with source and country. That tells you whether anyone is scanning the poster. A few honest limits:

- Stats are per link, not per person. If you print the same code in two places, they share one count. Make a separate short link and QR code per placement to compare them.
- It counts opens of the short link. Once someone is inside Drive, squish.to cannot see what they do there.
- You cannot change where an existing short link points. If the Drive link changes, make a new link and a new code. Reprinting is easier to avoid if you keep updating the same Drive file rather than replacing it with a new one.

## FAQ

**How do I make a QR code for a Google Drive folder?**
Set the folder to "Anyone with the link" as Viewer, copy the share link, paste it into squish.to, and download the QR code beside the short link.

**Why does my Google Drive QR code ask for access?**
The file or folder is still set to Restricted. Change General access to "Anyone with the link" and test again from a phone that is not signed in to your account.

**Does the QR code expire?**
A squish.to short link to a Drive file does not expire. The Drive link works until you change the sharing setting or delete the file. Only files uploaded to squish.to expire, after 30 days.

**Can I see how many people scanned it?**
Yes, as opens of the short link, per link rather than per person. Preview tools and scanners can occasionally add opens that no human made.

**Is the QR code free, and do I need an account?**
Yes, it is free and no account is needed.
